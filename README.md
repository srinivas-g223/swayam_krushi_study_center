# Swayam Krushi Study Centre

Responsive single-page website for Swayam Krushi Study Centre.

## Run locally

Open `index.html` in a browser, or run the zero-dependency development server:

```sh
npm run dev
```

Then open `http://localhost:5173`.

## Deploy

The site is static and can be deployed to Vercel from the project root. No build command or output directory is required. Connect the GitHub repository in Vercel, or deploy with the Vercel CLI using `vercel --prod`.

The current banner, About, and classroom images are in `images/hero-clear.png`, `images/books-clear.png`, and `images/class-clear.png`.
