SWAYAM KRUSHI STUDY CENTRE - single page website
================================================
EASIEST: double-click index.html (no install, no npm needed).
VS Code: open this folder, right-click index.html, "Open with Live Server".
OPTIONAL: npm run dev  -> http://localhost:5173  (only Node.js needed, nothing to install)

Active page photos: images/hero-clear.png, images/books-clear.png, and
images/class-clear.png. Replace these files to update the banner, About,
and classroom photos.
Edit phone / email / reviews in index.html and js/script.js (search "96765" and REVIEWS).
